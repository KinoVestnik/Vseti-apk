## Скачать

**[Скачать последнюю версию Vseti APK](https://github.com/KinoVestnik/Vseti-apk/releases/latest)**

Откройте раздел Releases, скачайте файл `Vseti-версия.apk` и установите его. На Android TV файл можно открыть через любой файловый менеджер.

## Что внутри

- стартовая страница `vseti.click`;
- интерфейс для Android и Android TV;
- квадратная фирменная иконка приложения;
- отдельный широкий баннер для лаунчеров Android TV;
- встроенная проверка новых версий;
- обновления только из этого официального репозитория Vseti.

## Обновление

Приложение само сообщит о новой версии. Все APK подписываются постоянным ключом Vseti, поэтому новая версия устанавливается поверх предыдущей без удаления приложения и настроек.

## Важно

Этот репозиторий предназначен для готовых стабильных сборок. Исходный проект основан на [lampa-app/LAMPA](https://github.com/lampa-app/LAMPA). Vseti является независимой пользовательской сборкой и не представляет официальный проект LAMPA.
